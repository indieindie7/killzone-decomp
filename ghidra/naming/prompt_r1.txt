PlayStation 2 game Killzone (Guerrilla Games / SCE, 2004, USA SCUS-97402). The program is the main ELF SCUS_974.02 (MIPS R5900 "Emotion Engine", GCC ee-gcc; .text at 0x00140000, size 0x3d3340, entry 0x00146f30; .data 0x00513380, .rodata 0x0053c980, .sdata 0x00558f80, .bss 0x0055b500; scratchpad data at 0x70003a00). Ghidra decoded it as generic MIPS64, so R5900 multimedia instructions (MMI: paddw, pextlw, pcpyld, qmtc2/qmfc2 = VU0 macro mode, lq/sq 128-bit loads) show up as bad or missing instructions, "halt_baddata()" or odd 64-bit code; treat such functions as vector/VU0 math or DMA packet builders. Research only. Game: first-person shooter on Vekta vs the Helghast; levels streamed from FILES.DAT packs; four relocatable overlays (BLGFX.REL, NETWORK.REL, ONLINE.REL, DNASMC.REL); online play (DNAS, SNAP/libnet); Logitech USB keyboard/mouse/headset drivers (LGKBM, LGAUD).

Some blocks carry a "/* decider hint: ... */" line with size, callee count and the strings the function references. Use them.
